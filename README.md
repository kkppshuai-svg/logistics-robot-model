# 物流赛机器人模型

物流赛机器人 SolidWorks 整车装配体及配套模型文件。

## 打开模型

使用 SolidWorks 打开仓库根目录的 `物流整车.SLDASM`。下载或克隆整个仓库，并保留原有文件名与目录结构，以便装配体查找配套零件。

## 文件内容

- `.SLDASM`：整车及子装配体。
- `.SLDPRT`：SolidWorks 零件。
- `.STEP` / `.stp`：交换格式模型。
- `.STL`：网格模型。
- 原目录附带的图片和演示视频。
